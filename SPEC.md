## 1. Философия продукта (главные правила)

### 1.1. Что мы делаем
Удобное приложение для целей, которым **приятно пользоваться**. Человек открывает его с удовольствием, всё работает плавно и понятно, а каждое действие даёт ощущение результата.

### 1.2. Чего мы НЕ делаем
- ❌ **Никакого «AI slop»**: шаблонного дизайна, бессмысленных градиентов, сгенерированных текстов-заглушек, фич «для галочки».
- ❌ **Никакой экономики внимания.** Приложение не должно «залипать» ради времени в приложении. Наша метрика — **выполненные цели**, а не минуты на экране.
- ❌ Никаких бесконечных лент, кликбейтных уведомлений и манипулятивных механик (FOMO, искусственная срочность, «вернись, мы скучаем»).
- ❌ Никакой перегрузки интерфейса: каждая кнопка должна быть нужна.

### 1.3. Принципы
1. **Приятно, но не затягивает.** Удовольствие как у лучших продуктов (плавность, отклик, чистота), но цель противоположная: зашёл, отметил, спланировал, ушёл заниматься делом.
2. **Экономия времени пользователя.** Любое основное действие (создать цель, отметить шаг) занимает не больше 2–3 касаний.
3. **Фокус на продуктивности.** Всё в приложении помогает делать, а не просто смотреть.
4. **Качество деталей:** микроанимации, тактильный отклик, аккуратная типографика, понятные пустые состояния.
5. **Честные уведомления:** только полезные и только те, что настроил пользователь.

## 2. Платформа и распространение (Бесплатно без App Store / Google Play)

### 2.1. Формат: PWA (Progressive Web App)
- **Технологический стек:** React + Vite + Tailwind CSS + PWA (Service Worker).
- **Деплой:** GitHub ➔ Vercel (полностью бесплатно, авто-деплой за 30 секунд по `git push`).
- **Хранение данных (MVP):** LocalStorage / IndexedDB (работает моментально, данные на устройстве пользователя, полная работа оффлайн).

### 2.2. Как пользователи устанавливают приложение:
- **iPhone (iOS):** Safari ➔ «Поделиться» ➔ «На экран “Домой”» (работает как нативное приложение на полный экран без рамок браузера).
- **Android:** Chrome ➔ «Установить приложение» (появляется иконка на рабочем столе и в списке приложений).
- **MacBook (macOS):** Safari/Chrome ➔ «Добавить в Dock / Установить» (появляется в Launchpad и Applications, открывается в отдельном окне).

## 5. Цель: поля и функции (MVP)

### 5.1. Поля цели
| Поле | Тип | Обязательное |
|------|-----|--------------|
| **Название** | текст | ✅ |
| **Описание** | текст | — |
| **Категория** | выбор из списка | ✅ |
| **Дедлайн** | дата (и время) | — |
| **Приоритет** | Низкий / Средний / Высокий | ✅ (по умолчанию «Средний») |
| **Период** | День / Неделя / Месяц / Год | ✅ |

### 5.2. Подцели и прогресс
- Цель можно разбить на **подцели (чек-лист шагов)**.
- **Прогресс считается автоматически**: выполнено подцелей / всего подцелей.
- Прогресс-бар отображается на карточке цели.

### 5.3. Уведомления
- Напоминания о цели в выбранное пользователем время.
- Напоминание о приближении дедлайна.
- Пользователь полностью управляет уведомлениями (включить, выключить, настроить время).

### 5.4. Категории
По умолчанию **6 категорий**:

| Категория |
|-----------|
| 💪 Здоровье |
| 💰 Финансы |
| 📚 Учёба |
| 💼 Карьера |
| ❤️ Отношения |
| 🎨 Хобби |

- ➕ Пользователь может **добавлять свои категории** (название, иконка/эмодзи, цвет).
- Можно редактировать и удалять пользовательские категории.

## 6. Бэклог: идеи на будущее (не в MVP)

> Добавляются только если реально помогают продуктивности, а не удерживают внимание.

### Мотивация (аккуратно, без манипуляций)
- Серия дней подряд (streak)
- Достижения за реальные результаты
- Личные награды, которые пользователь назначает себе сам
- Анимация при выполнении цели (короткая и приятная)

### Привычки и трекинг
- Привычки с расписанием (ежедневно / по дням / кастомно)
- Тепловая карта активности
- Измеримые цели с числовым трекером («100 км», «12 книг», «50 000 ₽»)
- Таймер / Pomodoro, привязанный к цели
- Заметки и дневник к цели

### Планирование
- SMART-мастер для постановки целей
- Цели на жизнь (долгосрочный горизонт)
- Еженедельный обзор: что получилось и что мешало
- Колесо баланса жизни
- Доска желаний (vision board)

### Социальные функции
- Партнёр по ответственности
- Совместные цели (семья, пара)
- Челленджи
- Карточка прогресса для шеринга

### Умные функции
- Автоматическая разбивка цели на шаги
- Прогноз успеха по текущему темпу
- Голосовой ввод

### Технические
- Виджеты на домашний экран
- Офлайн-режим и синхронизация
- Тёмная тема
- Экспорт (CSV/PDF), интеграция с календарём
- Интеграции: Apple Health, Google Fit
