## 🚀 Онлайн-версия (Live Demo)

> 🔗 **Ссылка на приложение:** `https://task-scheduler-rho-five.vercel.app` *(после подключения Vercel)*

### Как задеплоить бесплатно за 1 минуту:
1. Зайди на [vercel.com](https://vercel.com) и нажми **Sign Up** ➔ **Continue with GitHub**.
2. Нажми кнопку **«Add New...»** ➔ **«Project»**.
3. Выбери из списка репозиторий `abeke09340/Task_Scheduler` и нажми **«Import»**.
4. Ничего менять в настройках не нужно (Vite определится автоматически). Нажми **«Deploy»**.
5. Через 30 секунд у тебя появится бесплатная постоянная ссылка с HTTPS!

## 💻 Как установить приложение на Mac (как отдельную программу)

После перехода по ссылке в браузере приложение можно установить как родную программу для macOS:

### Вариант 1: Через Safari (рекомендуется)
1. Открой ссылку приложения в **Safari**.
2. В верхнем меню выбери: **«Файл» (File)** ➔ **«Добавить в Dock...» (Add to Dock...)**.
3. Нажми **«Добавить»**.
4. **Готово!** Приложение появится в панели Dock и в папке «Программы» (Applications). Оно открывается в собственном окне без адресной строки Safari, как нативное macOS-приложение, и работает даже без интернета.

### Вариант 2: Через Google Chrome
1. Открой ссылку приложения в **Google Chrome**.
2. В правой части адресной строки нажми на иконку **«Установить приложение»** (компьютер со стрелкой вниз).
3. Нажми **«Установить»**.
4. Приложение появится в Launchpad и в Dock в виде отдельного приложения.

## 📱 Как установить на телефон

* **iPhone (Safari):** Нажми кнопку **«Поделиться»** (квадрат со стрелкой вверх) ➔ выбери **«На экран “Домой”»** (Add to Home Screen).
* **Android (Chrome):** Нажми на всплывающее уведомление внизу **«Добавить на главный экран»** или в меню три точки ➔ **«Установить приложение»**.
